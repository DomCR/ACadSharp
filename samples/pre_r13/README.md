# Drawings older than R13

Sample drawings for the reader of R10 (`AC1006`) and R11/R12 (`AC1009`) drawings, used by
`DwgPreR13ReaderTests`.

The drawings come from the test data of these projects by Michal Josef Špaček, renamed after
their content:

- [CAD-Format-DWG-AC1006](https://github.com/michal-josef-spacek/CAD-Format-DWG-AC1006) → `AC1006/`
- [CAD-Format-DWG-AC1009](https://github.com/michal-josef-spacek/CAD-Format-DWG-AC1009) → `AC1009/`
