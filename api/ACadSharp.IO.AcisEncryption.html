Remarks

Supports ACIS text and binary encoding and decoding, binary signature detection, and trimming data at ACIS end markers.

Methods

Decode(byte[])

Decodes ACIS data that was encoded with Encode(byte[]), such as the SAT blocks stored in DWG files.

public static byte[] Decode(byte[] data)

Parameters

data byte[]

The data to decode.

Returns

byte[]

A new array with the decoded data, or the original data if it is null or empty.

Remarks

Bytes in the range 0x21 to 0x7E are mirrored (0x9F - b), every other byte is kept as is. The data is always decoded, it is not inspected with IsEncoded(byte[]), so Decode(Encode(data)) always returns the original data.

Returns

The decoded text, or the original text if it is null, empty or not encoded.

Remarks

Characters in the range 0x21 to 0x7E are mirrored (0x9F - c), every other character is kept as is. DXF caret escapes (^ , ^J, ^M, ^I) are expected to be already resolved by the DXF reader.

Returns

bool

true if the data is encoded; otherwise false, including when data is null, empty or contains only whitespace.

Remarks

Plain ACIS data starts with a number, so the data is considered encoded when its first non-whitespace byte is not an ASCII digit.
